KALIMAN - KO6EAI
For ATS Mini SI4732 ESP32-S3 units with the specified switch and headphone hardware.
Do not install on other variants without confirming compatibility.
Back up the original firmware before flashing.

This package uses huge_app.csv and does not enable OTA updates.
firmware.bin contains the application only; it is not a full flash backup.
FLASH-OFFSETS.txt lists the four USB recovery flash offsets.
SHA256SUMS.txt verifies file integrity; it is not a digital signature.
GitHub Actions builds and packages the firmware. It does not configure or deploy
to Schematik, and publishing a GitHub Release does not install firmware on a radio.
Configure Schematik separately to use this repository's main branch if it should
receive source updates. Verify the resulting build on compatible hardware before
recommending it to others.
Preserve all dependency and SSB patch license notices. The SSB patch has a
commercial redistribution restriction.
